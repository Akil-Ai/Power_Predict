# ⚡ Power_Predict (PowerPredict AI)

[![Platform](https://img.shields.io/badge/Target_Processor-AMD_Ryzen_AI-orange.svg)]()
[![Language](https://img.shields.io/badge/Language-HTML5/JS-red.svg)]()
[![ML](https://img.shields.io/badge/Type-Machine_Learning-blue.svg)]()

**PowerPredict AI** uses machine learning on real-time sensor data to predict faults in electric grids 24–48 hours in advance. Built to run efficiently on **AMD Ryzen AI processors**, it reduces power grid downtime by up to 40%, saving millions in operational losses.

---

## ✨ Features

*   **Real-time Sensor Monitoring:** Simulates or connects to electric grid sensors (voltage, current, temperature, frequency).
*   **Fault Prediction Engine:** Analyzes current trends to flags grid failures hours in advance.
*   **On-Device AI Optimization:** Structured to execute lightweight models locally using Ryzen AI hardware acceleration features.
*   **Single Page Dashboard:** Fast, web-based visual interface inside `powerpredict.html`.

---

## 🛠️ Technology Stack

*   **Frontend Layout:** HTML5, CSS3, Vanilla JavaScript
*   **ML Engine Integration:** ONNX Runtime Web / TensorFlow.js configured for local NPU execution.

---

## 🚀 How to Run

1.  Clone the repository:
    ```bash
    git clone https://github.com/Akil-Ai/Power_Predict.git
    cd Power_Predict
    ```
2.  Open `powerpredict.html` directly in your web browser, or host it locally using a simple python web server:
    ```bash
    python -m http.server 8000
    ```
3.  Access the page via `http://localhost:8000/powerpredict.html`.
